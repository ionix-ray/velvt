# Security & Compliance Matrix — Vaelvet

Enterprise security posture of this repository: Dioxus WASM static site (`velvet-ui/`) + Axum static file server (`server/`), distroless container, GitHub Pages + GHCR container deploy.

**Rules of this document**
- Every row cites `file:line` as observed in the working tree (re-verified at time of writing).
- Anything not yet in the tree is explicitly marked **in progress** or **backlog** with an `S6-xx` ID (next sprint) and a P-level.
- Verification tests cited are the tests that actually assert the control.
